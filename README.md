#Mars Sample Return Mission

Учебный проект, в котором реализована система для автоматизации отправки миссий на Марс, 
которое состоит из веб-приложения, веб-сервиса и десктопного приложения

Основное назначение разработанной системы заключается в автоматизации процесса отправки космических миссий на Марс для сборки грунта в гильзы-пробирки. 
Система позволит планировщикам миссий просматривать всю необходимую информацию об образцах. 
Также она позволит планировщикам миссий – быстро и легко отправлять космически миссии для сбора грунта, создавая заявки на их отправление, 
а кураторам – принимать / отклонять их.
